# Altimeter

Altimeter connects to your WiFi network through a self-service setup
page on the device itself — no app to install, no computer or cable
required beyond the one-time setup.

## Start here

- **[Getting Started](getting-started.md)** — connect the device to
  your WiFi network for the first time
- **[Factory Reset](factory-reset.md)** — erase saved WiFi credentials
  and start setup over
