# Factory Reset

Erasing the saved WiFi credentials and returning the device to setup
mode doesn't need a computer — it's a single button on the device.

## When to do this

- Moving the device to a different WiFi network
- The saved WiFi password changed
- The device won't connect and you want to start setup over

## How

1. Locate the **BOOT** button on the device.
2. Press and hold it for about **8 seconds**.
3. The status LED goes solid amber once the credentials are erased and
   the device reboots into setup mode.
4. Follow [Getting Started](getting-started.md) to reconnect it.

Holding the button for less than 8 seconds does nothing — release it
early and the device carries on as normal, still connected.
